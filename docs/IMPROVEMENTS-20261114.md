# NoticeMe 本轮改进方案与验收

## 基线与备份

- 基线：v0.4.3，提交 `1d0d494`，原工作区干净。现有能力包括任务、提醒、今日聚焦、日记、文件夹笔记和可选本地 AI。
- 修改前备份：`G:/DSH_Coding/_backups/noticeme-before-optimization-20261114/`，包括完整 Git bundle（verify 通过）、源码 ZIP、真实 `data.json` 及全部历史备份的副本和 SHA256 清单。
- 回退标签：`noticeme-v0.4.3-backup-20261114`。在独立 `codex/noticeme-improvements-20261114` 分支实施。
- 所有运行测试使用独立临时数据目录，不启动共用正式数据目录的 dev 模式，不删除个人记录，不向 GitHub 提交个人数据与本地备份。

## 工作方案

1. **产品与界面**：今日聚焦增加手动任务选择和过往计划承接，保留 AI 预览确认；计划变动不改变截止时间；完善进度、空状态和键盘操作。
2. **数据可靠性**：损坏主文件留档并从有效快照恢复；无有效备份时明确停止，避免默认数据覆盖；每日快照清理不能误删导入留底；写入失败不提交内存变更。
3. **编辑可靠性**：修复日记、笔记与任务详情的延迟保存竞争，防止切换丢字、删除复活、旧草稿覆盖即时属性；显示失败并支持重试。
4. **任务信息**：按实际完成日期统计今天完成的任务；修正未设日期的排序；搜索与当前视图范围一致；常驻跨天及恢复窗口后刷新日期；完成状态和计划日期如实标注。
5. **验收与交付**：纯逻辑回归、类型检查、生产构建、隔离 Electron 交互/截图、真实数据哈希复核；生成 Windows 产物并将代码与回退标签推送远端。

## 交付与使用

- Windows 安装版：`dist/0.5.0/NoticeMe-Setup-0.5.0.exe`。
- Windows 便携版：`dist/0.5.0/NoticeMe-Portable-0.5.0.exe`。
- 可复验打包程序：`node scripts/smoke.mjs "<NoticeMe.exe 的绝对路径>"`。每轮输出到 `smoke-out/<时间戳>/`，报告缺失、进程失败、截图缺失、退出输入未落盘均使脚本失败。
- 测试模式禁用自动更新，防止验收期间下载或安装其他发布版本。
- 两份可执行文件的完整 SHA256 清单位于本机 `dist/0.5.0/SHA256SUMS.txt`。
- 本轮没有执行安装器覆盖现有应用，没有上传 Release 资产。Git 代码同步与安装版本更新是两件事；安装本地新包后继续使用原正式数据目录。
- 若要回退代码，使用本轮提交的 `git revert` 生成回退提交，或在备份标签新建独立分支查看旧代码。不要重写共享历史，不要删除 AppData。源码备份、数据备份与新安装包相互独立。

## 已知边界

- 未在 macOS 构建/实测，未重下载或重测本地 AI 模型推理性能。
- 跨日行为通过日期固定/旧计划注入和时区测试验证，没有等待真实午夜；键盘实测覆盖 Esc 和 Ctrl+F，不等同于全部辅助技术验收。
- “今天完成”仅统计当前记录中 `done=true` 且 `completedAt` 在今天的任务。重复任务完成时会推进下一次且无独立完成日志，因此不计入此数；界面提示已说明，未补造历史记录。
- 正常退出时等待保存；磁盘写入失败保留会话草稿并阻止退出。强杀、断电或系统崩溃不能保证内存草稿落盘，仍应定期导出完整备份。
- 导入/导出/点击更新入口已增加保存屏障；原生文件选择与更新安装器未通过自动化执行真实覆盖/升级。数据替换及失败回滚由存储专项覆盖，导入明确二次确认。
