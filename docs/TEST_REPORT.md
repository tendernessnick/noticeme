## 2. 单元测试覆盖

- **解析器**：标题抽取、p1-P4/!N（含词中不误判）、今天/今晚/明天/后天、周X/下周X/下下周X、X月X日（今年/翻年）、YYYY-MM-DD、N分钟后、下午3点半、**中文数字（晚上八点）**、HH:mm 合法性、时间已过顺延明天、#项目 @多标签
- **重复规则**：每天/间隔 N/逾期推进到未来/每个工作日（周五→周一）/每周/每月（1月31→2月28 钳制）/每年（闰日→2月28）/无规则 null
- **调度核心**：到点触发+防重键、提前 N 分钟提醒、未到不触发、已消费不重弹、错过窗口外静默标记、已完成/无日期不触发、贪睡到点消费/未到保留/指向已完成任务
- **存储**：默认初始化、读写往返、原子写入（无 .tmp 残留）、当日备份、损坏自愈留档、导出导入往返+导入留底、非法导入拒绝、onChange 通知

**通过（12 条）**：#1 到点呈现（10s 扫描周期内，卡片不抢键盘焦点）、#2 重启补发（启动即扫描；冒烟实测跨运行补发）、#7 NL 全要素（测试覆盖）、#8 N分钟后、#12 今天视图分组、#15 完成划线与恢复、#17 关闭驻留托盘+单实例（角标差异见下）、#19 跟随系统主题即时切换（双主题截图取证）、#21 导出导入还原、#23 断网可用（架构零外联）、#24 备份保留 7 份、#22 冷启动（实测 ~1.8s 可交互）

## 4. 迭代中发现的缺陷与修复（均已回归通过）

| # | 缺陷 | 级别 | 修复 |
|---|---|---|---|
| B1 | 主进程直接变更（注入/调度消费）不广播渲染端，两端数据不一致 | P0 | `store.onChange` 统一广播到全部窗口 + 刷新托盘 |
| B2 | 提醒卡片页在 IPC 推送后才完成加载 → 显示「0 条」空卡片（竞态） | P0 | `did-finish-load` 重发 + 渲染端挂载 `alert:sync` 主动拉取，双保险 |
| B3 | 「下周一」正则可选组回溯丢失「下周」前缀 → 解析为本周 | P1 | 前缀改 `(下{1,2})?` 整体匹配，回归测试覆盖 |
| B4 | 全新安装（未落盘）直接导入备份 → ENOENT 崩溃 | P1 | 备份留底加存在性守卫，回归测试覆盖 |
| B5 | 冒烟数据目录跨运行复用 → 演示数据重复 | P2 | 每次冒烟独立临时目录 |
| B6 | 演示提醒时点早于 10s 扫描 tick，截图窗口错过弹窗 | P2 | 调整演示时序与等待窗口 |
| B7 | 打包 winCodeSign 需符号链接特权（Windows 无开发者模式） | P2 | `signAndEditExecutable: false` 规避，见 §5 |

## 5. 打包说明与遗留风险

- `dist/NoticeMe-Setup-0.1.0.exe`：✅ NSIS 安装包（84 MB，可选安装目录、桌面快捷方式）
- `dist/NoticeMe-Portable-0.1.0.exe`：✅ 免安装便携版（84 MB）
- `dist/win-unpacked/NoticeMe.exe`：✅ 解包目录可直接运行
- 打包环境适配记录（已固化到配置/RUNBOOK）：`electronDist: node_modules/electron/dist`（离线复用本地 Electron）；NSIS 插件缓存补齐；`ELECTRON_BUILDER_BINARIES_MIRROR` 走 npmmirror；`signAndEditExecutable: false` 规避符号链接特权（exe 文件图标为默认，运行中窗口/托盘/弹窗图标均为 NoticeMe 自绘图标）
- 遗留风险：10s 扫描周期使提醒呈现存在最多 10s 抖动（满足 PRD ≤10s 上限，如需秒级可加 per-task timer，见 TECH_DESIGN §8）；系统通知在未打包 dev 模式下部分环境不可用（弹窗卡片主通道不受影响）
