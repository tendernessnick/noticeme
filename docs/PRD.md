| 贪睡/持续提醒 | 无原生贪睡 | 有（Snooze，间隔可调） | 无原生贪睡 | 无 | **有（5/10/15/30/60 分钟）** |

| 开源 | 否 | 否 | 否 | 是（GitHub 活跃） | 是（本项目） |

### 1.2 竞品调研结论与启示

1. **Todoist**：自然语言快速添加（`#`项目、`@`标签、`!`提醒、日期短语）是效率标杆；全局快速添加快捷键让"捕捉想法"零摩擦；界面干净克制，暗色主题与系统联动。→ NoticeMe 必须有同等水平的快速添加体验，且解析要支持中文。
2. **滴答清单 TickTick**：中文场景的时间解析（"明天下午3点""30分钟后"）与多级提醒、持续提醒（Snooze）做得最贴合国内用户；但核心提醒能力与云同步绑定、部分功能付费。→ NoticeMe 把"多提醒 + 贪睡 + 持续提醒"作为免费核心能力，这是对竞品付费墙的直接差异化。
3. **Microsoft To Do**：My Day 视图（2025-10 起自动填充今日到期任务）验证了"今天"视图是用户第一入口；但提醒弱、依赖微软账户、离线体验差。→ NoticeMe 的"今天"视图设为默认首页。
4. **Super Productivity**：验证了"离线优先 + 无账户 + 托盘常驻"的桌面待办可行且受开源社区欢迎；但界面朴素、中文支持弱、提醒非其核心。→ NoticeMe 取其"本地优先"哲学，但以"提醒可靠性 + 精美界面"为核心卖点。
5. **其他开源 Electron 应用（OpenTodo、peakflow-electron 等）**：多数开源桌面待办在"提醒可靠性"上普遍薄弱（依赖系统通知、被勿扰模式吞掉、错过不补发）。→ 提醒可靠性是 NoticeMe 最核心的差异化战场，具体方案见第 5 章。
6. **本地化洞察**：Todoist 默认全局快捷键 Ctrl+Space 与中文输入法切换键冲突，国内用户必须改键。→ NoticeMe 默认快捷键避开 Ctrl+Space。

## 2. 产品定位与目标用户

### 2.1 一句话定位

> 一款**本地优先、提醒足够可靠、界面精美**的 Windows 桌面待办 + 提醒应用，为"每天待办很多、经常忘记事情"的个人用户服务。

### 2.2 目标用户

| 维度 | 描述 |
|---|---|
| 主要用户 | 开发者/效率工具重度使用者（本项目作者自用为第一优先），日常在电脑前工作，每天 10+ 条待办 |
| 核心痛点 | ① 事情多、容易忘，现有工具提醒不及时或被系统吞掉；② 云端工具要登录、隐私顾虑；③ 国内网络下国际工具体验打折 |
| 使用场景 | 工作中随手快速添加任务（全局快捷键）；专注时被弹窗提醒拉回正轨；下班前检查"今天"视图 |

### 2.3 产品原则（决策依据，后续功能取舍以此为准）

1. **提醒 > 一切**：任何功能妥协不能牺牲提醒的及时性与可靠性。
2. **本地优先**：无账户、无网络请求、数据可随时导出带走。
3. **键盘优先**：高频操作（添加、完成、切换视图）全程可不碰鼠标。
4. **少而精**：MVP 只做核心闭环（记录 → 提醒 → 完成），拒绝功能堆砌。

## 3. MVP 功能清单

### 3.0 范围总览与调整说明

在给定骨架基础上做如下微调（均为降低 MVP 风险或补齐闭环）：

| 调整 | 理由 |
|---|---|
| 任务增加"备注"字段 | 详情抽屉编辑，成本极低，Todoist/MSToDo 均有，搜索也需要 |
| 手动拖拽排序移出 MVP，使用固定智能排序 | 拖拽排序 + 排序持久化工作量不小且非核心痛点；智能排序（逾期置顶→优先级→截止时间）已满足"先做重要的事" |
| 快速添加不支持额外提醒语法（`!`时间） | 中文时间解析歧义多、测试面大；MVP 约定"有截止时间的任务默认准时提醒"，多提醒在详情面板设置，V2 再考虑语法 |
| 项目支持删除但删除前强制确认并提示任务去向 | 防止误删丢数据，纯本地无撤销服务，必须有确认 |
| 系统通知为"可选降级方案"，默认使用自绘置顶弹窗 | Windows 专注助理/勿扰会吞掉系统通知，与"提醒可靠性"目标冲突；自绘窗口不受影响（详见 5.4） |

### 3.1 任务管理

- **CRUD**：创建（快速添加框 / 详情抽屉 / 托盘菜单）、编辑（详情抽屉或双击行内编辑标题）、删除（右键菜单 + Del 键，删除需确认）。
- **完成勾选**：点击复选框即完成；已完成任务从活动视图消失，进入"已完成"视图；支持撤销完成（已完成视图内取消勾选，或完成后 5 秒内的 toast 撤销入口）。
- **优先级 P1–P4**：P1 最高。P1 红 / P2 橙 / P3 蓝 / P4 灰（无旗帜）。任务行以旗帜图标着色展示（不用整行色条，保持 Todoist 式克制）。
- **标签**：全局标签池，一个任务可挂多个；标签可管理（重命名/删除，删除标签自动从任务摘除）。
- **项目（清单）**：默认项目"收件箱"（Inbox，不可删除）；用户可建项目（名称 + 12 色可选）；支持归档项目（归档后任务保留但入口折叠）。
- **备注**：多行纯文本（MVP 不做富文本/Markdown 渲染）。
- **排序规则（固定）**：逾期置顶 → 今天到期 → 有截止时间（按时间升序）→ 无截止时间；同组内 P1→P4，再按创建时间。

### 3.2 提醒系统

- **截止时间**：精确到分钟；支持"全天"任务（全天任务无时间提醒，仅在当天视图高亮，不弹窗）。
- **多提醒**：每个任务可设 0–5 个提醒；每个提醒 = 准时（offset=0）或提前 N 分钟（可选值：5/10/15/30/60/120/1440）。
- **贪睡**：提醒卡片上直接贪睡，选项 5/10/15/30/60 分钟；贪睡在设置中可配置默认项。
- **未处理循环提醒（默认关闭，设置中开启）**：某条提醒触发后若未被"完成/关闭/贪睡"处理，每 5 分钟重复弹一次，最多重复 3 次，之后静默并在"今天"视图高亮该任务。
- **提醒上限保护**：同一任务同一时刻最多同时展示 1 张卡片，多条提醒合并进一张卡片（列表展示）。

### 3.3 重复任务

| 周期 | 语义 |
|---|---|
| 每天 | 每日一次，含周末 |
| 每个工作日 | 周一至周五 |
| 每周 X | 指定星期几（可选多选，如"每周一、周四"） |
| 每月 X 号 | 每月固定日期；当月无该日期（如 31 号）则跳过当月 |
| 每年 X 月 X 号 | 每年固定日期 |

- **推进机制**：完成当前实例时，立即按规则生成下一次到期时间（含提醒时间同步平移），当前实例转入已完成。**未完成也推进**：若到期日已过且任务未完成，视图中的重复任务始终显示"下一次待办期"，避免堆积僵尸任务；历史逾期实例自动记为"已跳过"（在已完成视图以"跳过"标记展示）。
- 重复任务编辑时询问"仅此实例 / 所有后续"。

### 3.4 视图与搜索

- **视图（左侧栏固定导航）**：
  - **今天**（默认首页）：逾期 + 今日到期 + 今日提醒的任务；顶部显示进度（已完成/总数）。
  - **即将到来**：未来 7 天，按天分组（明天/周三/…/下周 X）。
  - **全部**：所有未完成任务（按 3.1 排序规则）。
  - **已完成**：按完成时间倒序，支持按日筛选（近 7 天/近 30 天/全部）。
  - **按项目**：项目列表逐项展开；含归档区。
- **搜索**：Ctrl+F 聚焦搜索框；匹配标题与备注；支持 `#项目名` `@标签名` 过滤前缀（可组合，如 `开会 #工作 @紧急`）；结果页高亮命中词。

### 3.5 快速添加与中英文自然语言解析

**入口**：① 主窗口列表顶部常驻快速添加框（Enter 提交，Esc 清空）；② 全局快捷键呼出的迷你快速添加窗（见 3.6）。

**解析规则**（输入 → 结构化字段，解析词从标题中剥离；输入框下方实时显示解析预览 chips）：

| 类型 | 中文示例 | 英文示例 | 解析结果 |
|---|---|---|---|
| 日期+时间 | 明天9点 / 后天下午3点半 / 下周五晚上8点 / 周三上午10点 | tomorrow 9am / next friday 8pm / wed 10:30am | dueDate |
| 相对时间 | 30分钟后 / 2小时后 / 半小时后 | in 30 minutes / in 2 hours | dueDate = now + delta |
| 今天/今天几点 | 今天 / 今天下午5点 | today / today 5pm | dueDate |
| 重复 | 每天X / 每个工作日X / 每周一X / 每月15号X / 每年3月1号X | every day X / every monday X / monthly on the 15th | repeat + 起始 dueDate |
| 优先级 | p1 / P1 | p1 | priority（不区分大小写） |
| 项目 | #工作 / #项目名（支持中文，取最长匹配） | #work | projectId（不存在则自动创建该项目） |
| 标签 | @紧急 / @tag | @tag | labelId（不存在则自动创建该标签） |

**歧义与边界规则**：
- "X点"未标注上午/下午时：1–6 点默认按下午（口语习惯，"3点"=15:00），7–11 点默认上午，12 点=12:00，0 点=00:00；标注"上午/早上/am/凌晨"则按上午，"下午/晚上/pm"则 12 小时制 +12（"晚上8点"=20:00，"晚上12点"=24:00 即次日 00:00）。
- 已过去的当日时间（如现在 15:00 输入"今天9点"）自动顺延到明天，并在解析预览中提示。
- 时间单位冲突时后者覆盖前者；仅日期无时间 → 全天任务；仅时间无日期 → 今天。
- 解析失败的词保持原样留在标题中（不吞用户文字）。

**示例**：输入 `明天9点 给客户发合同 p1 #工作 @重要` → 标题=`给客户发合同`，due=明天 09:00，P1，项目=工作，标签=重要，自动带准时提醒。

### 3.6 系统集成

- **系统托盘**：
  - 托盘图标常驻；图标角标显示**今日未完成任务数**（0 条时显示普通图标）。
  - 左键单击：显示/隐藏主窗口。
  - 右键菜单：快速添加（呼出迷你窗）、今天（N 条未完成）、显示主窗口、开机自启（勾选项）、退出。
- **置顶弹窗提醒卡片**（默认提醒方式，自绘 frameless 窗口）：
  - 位置：主显示器右下角（托盘上方），多张卡片垂直堆叠（最多同时 3 张，其余排队）。
  - 不抢键盘焦点（见 5.4）；鼠标悬停时暂停自动消失倒计时。
  - 内容：任务标题、截止时间、所属项目色点；操作按钮：完成 / 贪睡（默认间隔下拉）/ 打开（聚焦主窗口并定位该任务）。
  - 未处理时停留至用户操作或循环提醒逻辑接管；处理后 200ms 滑出动画。
- **Windows 系统通知**（设置中可切换为"使用系统通知"）：作为降级/偏好方案；文案与卡片一致；点击通知打开主窗口定位任务。默认关闭（理由见 5.4）。
- **提示音**：内置 3 种音效（清脆/柔和/双响），音量滑杆；支持自定义 .wav/.mp3 文件路径；可静音。
- **全局快捷键**（设置中可自定义，冲突时提示）：
  - 快速添加：默认 `Ctrl+Alt+N`
  - 显示/隐藏主窗口：默认 `Ctrl+Alt+S`
  - 明确禁用 `Ctrl+Space`（中文输入法冲突）
- **开机自启**：设置开关，走系统注册表 Run 项（Electron 标准能力）；自启时仅启动托盘不弹主窗口。
- **关闭行为**：点窗口关闭按钮 = 最小化到托盘（设置可改为"直接退出"，改退出时需二次确认）。
- **单实例**：二次启动不产生新进程，激活已有主窗口（Electron 单实例锁）。

### 3.7 主题

- 三档：亮色 / 暗色 / 跟随系统（默认跟随系统；手动选择后覆盖系统值）。
- 切换即时生效（CSS 变量），无需重启。

### 3.8 数据存储、备份与导入导出

- **存储**：单文件本地 JSON（结构见附录 A），路径 `%APPDATA%/NoticeMe/data.json`。
- **写入策略**：变更防抖 500ms 合并写入；**原子写入**（先写临时文件再原子替换，防止断电/崩溃损坏）。
- **每日备份**：每天首次写入时自动备份前一日数据至 `%APPDATA%/NoticeMe/backups/`，命名 `backup-YYYY-MM-DD.json`，保留最近 7 份，超出自动清理。
- **启动自检**：启动时解析主文件失败 → 自动从最近备份恢复并弹 toast 告知用户"数据已从备份恢复"。
- **导入/导出**：设置页提供"导出全部数据（JSON）"与"从 JSON 导入"（导入前校验 schema，提供合并/覆盖两种策略，覆盖需二次确认）。导出文件即完整备份，可迁移到新电脑。

## 4. UI/UX 设计规范

### 4.1 整体布局

```
┌──────────┬──────────────────────────────┬──────────┐
│ 左侧栏    │  主列表                       │ 详情抽屉  │
│ 240px    │  flex 自适应                  │ 320px    │
│          │                              │ (可关闭)  │
│ 快速入口  │  ┌ 快速添加框 ─────────────┐  │ 任务标题  │
│ ·今天     │  └──────────────────────┘  │ 项目/标签 │
│ ·即将到来 │  任务行 …                   │ 优先级    │
│ ·全部     │  任务行 …                   │ 截止时间  │
│ ·已完成   │  任务行 …                   │ 提醒列表  │
│ ───────  │  任务行 …                   │ 重复规则  │
│ 项目列表  │  （空状态 / 已完成折叠区）      │ 备注      │
│ ·收件箱   │                              │          │
│ ·工作     │                              │          │
└──────────┴──────────────────────────────┴──────────┘
```

- 主窗口默认尺寸 1100×720，最小 860×560，位置与尺寸记忆。
- 详情抽屉默认关闭；点击任务行展开（从右滑入 200ms）；同一时间只展示一个任务。
- 左侧栏项目项支持右键菜单：重命名 / 改色 / 归档 / 删除（删除需确认，任务移入收件箱）。

### 4.2 设计 Token（CSS 变量级规范）

**字体栈**：`Inter, "Segoe UI", "Microsoft YaHei UI", "PingFang SC", sans-serif`（数字用 `font-variant-numeric: tabular-nums` 保证时间列对齐）。

**字号 / 行高**：

| Token | 值 | 用途 |
|---|---|---|
| font-size-xs | 12px / 16px | 辅助信息、时间戳、chips |
| font-size-sm | 13px / 18px | 左侧栏、次要文本 |
| font-size-md | 14px / 20px | **任务标题（默认）**、正文 |
| font-size-lg | 16px / 22px | 分组标题 |
| font-size-xl | 20px / 26px | 视图页标题（"今天"） |

## 5. 提醒可靠性需求（核心差异化）

### 5.1 及时性：秒级触发

- 调度模型：**主进程单一调度器，每秒轮询一次"待触发提醒队列"**（对全体任务按提醒时间索引），不采用每任务一个 setTimeout（避免数量膨胀与睡眠唤醒失准）。
- 触发判定：`now >= remindAt && reminder.status === pending`；触发后立即置为 `fired`，写盘后再弹窗（保证崩溃重启不重复弹）。
- 目标：到点后 **≤ 3 秒**内弹出卡片 + 声音（含系统休眠唤醒场景，唤醒后立即执行一次补偿扫描）。
- 时间源：统一使用主进程系统本地时间；每次窗口聚焦、每 60 秒与系统时间对账，防止长驻进程时钟漂移。

### 5.2 错过提醒补发策略

- 适用场景：应用未运行期间到点的提醒（含电脑睡眠）。
- 规则：应用启动（或从睡眠唤醒）后扫描所有 `fired=false && remindAt < now` 的提醒：
  - 错过 ≤ 30 分钟：**逐条补弹**，卡片标注"已错过，原定 HH:mm"；多条合并堆叠。
  - 错过 > 30 分钟：**聚合成一张汇总卡片**："错过了 N 条提醒"，点击展开列表逐条处理（完成/贪睡/打开）。
  - 重复任务的错过实例不补弹（由 3.3 推进机制处理），仅在"今天"视图中高亮。
- 补发动作在启动完成后 5 秒内发生，且不阻塞主窗口加载。

### 5.3 贪睡与循环提醒

- 贪睡：卡片操作，生成一条新的 pending 提醒（= now + 间隔），原提醒标记 `snoozed`；贪睡链不限次数。
- 未处理循环提醒（默认关）：触发后未处理时每 5 分钟重弹，最多 3 轮，每轮弹卡片文案提示剩余轮次。

### 5.4 弹窗不抢焦点但必须"被看见"

产品决策：**默认不使用 Windows 系统通知作为提醒通道**。原因：Windows 专注助理/勿扰模式/全屏应用规则会静默吞掉系统通知（TickTick 官方文档也要求用户手动检查系统通知权限），这与"提醒足够可靠"的核心目标冲突。因此：

- 提醒卡片为自绘置顶窗口：`always-on-top` + **不夺取键盘焦点**（以非激活方式显示，用户当前输入流不中断）；点击卡片后窗口才获得焦点。
- 提示音经系统音频通道播放，不受勿扰影响（音量为 0 时静音）。
- **任务栏闪烁**：卡片弹出后主窗口任务栏图标闪烁（flashFrame 语义），直到用户处理提醒或打开主窗口。
- 全屏应用场景：卡片仍置顶显示（用户可在设置中改为"全屏时只闪任务栏+声音"，尊重游戏/演示场景）。
- 系统通知作为可选降级（默认关）：供偏好系统通知中心聚合的用户使用；开启后卡片与系统通知二选一。

### 5.5 数据一致性

- 提醒状态变更（fired/snoozed/done）即时落盘（不走 500ms 防抖），防止崩溃后重复提醒或漏提醒。

## 7. 验收标准清单（逐条可测试）

**提醒可靠性**

1. 创建任务设 1 分钟后提醒，到点后 **10 秒内**（目标 3 秒）出现置顶弹窗与提示音，且当前窗口焦点未被打断。
2. 设 1 分钟后提醒，创建后立即强杀进程，2 分钟后重新启动应用，启动后 **5 秒内**出现补发卡片（标注"已错过"）。
3. 制造 5 条错过超 30 分钟的提醒，启动后仅出现 **1 张**汇总卡片，点击可展开 5 条并逐条处理。
4. 卡片上点击"贪睡 5 分钟"，5 分钟后（±10 秒）再次弹窗；任务栏图标在弹窗期间闪烁。
5. 开启"未处理循环提醒"，触发后不处理，每 5 分钟重弹，第 3 轮后停止并在"今天"视图高亮。
6. 电脑睡眠跨过提醒时间点，唤醒后 1 分钟内补弹。

**任务与解析**

7. 快速添加输入 `明天9点 给客户发合同 p1 #工作 @重要`，生成的任务：标题=“给客户发合同”、due=明天 09:00、P1、项目=工作、标签=重要，预览 chips 与最终结果一致。
8. 输入 `30分钟后 站起来喝水`，due = 当前时间 + 30 分钟（±1 分钟）。
9. 输入 `每周一 交周报`，生成本周一 due + "每周一"重复规则；勾选完成后自动生成下周一实例。
10. 输入 `每月31号 发工资`，在 2 月创建时下一次到期日为 3 月 31 日（跳过无 31 号的月份）。
11. "3点开会 今天"在下午 15:00 输入时，解析为明天 15:00 并在预览中提示顺延。

**视图与交互**

12. "今天"视图包含：所有逾期任务 + 今日到期任务；顶部计数 = 已完成/总数，且与实际一致。
13. 搜索 `开会` 在"全部"视图能返回所有标题或备注含"开会"的任务；`开会 #工作` 只返回工作项目内的结果。
14. ↑/↓ 可在任务行间移动焦点，Space 完成勾选，Enter 打开详情抽屉。
15. 完成勾选后出现划线 + 收拢动画；"已完成"视图可查到该任务并支持取消勾选恢复。

**系统集成**

16. 应用任意其他程序在前台时按 `Ctrl+Alt+N`，**500ms 内**弹出迷你快速添加窗，录入回车后任务落库且窗口自动关闭。
17. 点击窗口关闭按钮，应用驻留托盘、主进程存活；托盘角标数字 = 今日未完成任务数；再次启动应用不产生第二个实例而是激活已有窗口。
18. 开启开机自启后重启系统，应用自启且仅出现在托盘、不弹主窗口。
19. 系统在亮/暗模式间切换且 NoticeMe 主题为"跟随系统"时，界面在 1 秒内完成切换且无硬编码色残留（抽查任务行、弹窗、菜单、滚动条）。

**数据与性能**

20. 手动将 data.json 破坏为非法 JSON 后启动，应用自动从最近备份恢复，toast 提示"数据已从备份恢复"，任务完整。
21. "导出全部数据"得到的 JSON 在全新环境"导入（覆盖）"后，任务/项目/标签/设置完整还原；导入（合并）不产生重复任务。

23. 断网（禁用网卡）下全部功能可用；抓包确认进程无任何外联请求。
24. 备份目录连续运行 8 天后仅保留最近 7 份 `backup-YYYY-MM-DD.json`。
