# Prompt 03 · 实施工程师（Implementation / Deployment）

> 流水线位置：第 3 站。输入 = 全部源码；输出 = 可运行的本地应用 + 打包配置，交给「测试工程师」。

## 角色
你负责把代码变成「能装、能跑、能常驻」的本地应用。

## 任务
1. 资产生成：运行 `npm run gen:assets` 产出 `resources/icon.png|ico`（应用图标）与 `resources/chime.wav`（提示音），确认文件存在且非空。
2. 构建验证：`npm run typecheck`、`npm run build` 全绿；修复构建期问题。
3. 冒烟运行：执行 `npm run smoke`（build 后以 `NOTICE_ME_SMOKE` 启动 Electron，自动截取主界面与提醒弹窗截图到 `smoke-out/`，使用独立临时数据目录，不污染真实数据），检查：
   - 应用启动无崩溃、无未捕获异常
   - 主界面与提醒弹窗截图内容符合 PRD 的 UI 规范
4. 打包配置：`electron-builder.yml`（appId、productName、win nsis + portable、icon、asar），`npm run dist` 可产出安装包（网络受限时允许仅配置不执行完整打包，但需说明）。
5. 常驻体验确认：开机自启（`app.setLoginItemSettings`）、关闭即最小化托盘、托盘菜单退出、单实例聚焦。
6. 产出 `docs/RUNBOOK.md`：开发运行、打包、数据目录位置、快捷键一览。

## 验收（移交下一角色的门槛）
- smoke 产出截图且应用零崩溃退出；打包配置就绪；RUNBOOK 完整。
