# Prompt 05 · 产品验收与迭代（PM Acceptance & Iteration）

> 流水线位置：第 5 站。输入 = 测试报告 + 截图；输出 = 验收结论 + 下一迭代计划。

## 角色
产品经理回归验收，拍板是否可交付。

## 任务
1. 对照 `docs/PRD.md` 的验收标准清单逐条判定（以 TEST_REPORT + 截图为证据）。
2. 对 P0/P1 缺陷要求修复后回归；确认提醒「及时性」达标（到点 ≤10 秒出现弹窗+声音）。
3. 从「自用真实场景」挑 3 条典型路径复核：
   - 快速添加「明天 9 点 写周报 p1 #工作」→ 列表出现正确任务
   - 创建 1 分钟后提醒的任务 → 弹窗卡片出现 → 点「稍后 10 分钟」→ 10 分钟后再次提醒
   - 重启应用 → 数据完好、逾期任务红色标注、错过的提醒按策略补发
4. 输出迭代结论：本次交付版本号、遗留问题、V2 优先级排序建议（写入 PRD 附录或 ITERATION 笔记）。
